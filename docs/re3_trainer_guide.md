> 适用游戏：生化危机3 重制版 / Resident Evil 3 (2020)（Steam 版，仅单机离线）

## 一、它是什么，能做什么

这是一个**单机修改器**，装在 REFramework 里，随游戏自动加载。它可以：

| 功能 | 一句话说明 |
|---|---|
| 无敌 | 受到攻击不掉血 |
| 一击必杀 | 敌人挨一下就死 |
| 无限弹药 | 弹匣基本不用装填 |
| 无限物品 | 药草、手雷等消耗品不减少 |
| 小刀耐久检测 | 目前只检测，暂不修改 |
| 完美闪避 | 随时可以紧急闪避 |
| 游戏速度 | 慢动作（0.1x）到快进（5x） |
| 回满血量 | 一次性恢复到正常上限 |
| 游戏道具箱 | 把道具箱里的物品取到背包 |
| 刷取物品 | 任意物品直接放进背包（没拿过的也行） |
| 刷取武器 | 任意玩家武器直接放进背包（每把只刷一次） |

**不能做的事**：联机使用、修改存档文件本体、给武器加配件（武器刷出来是无配件、1 发弹药）。

## 二、使用前的准备

### 2.1 需要安装的东西

1. **REFramework**（修改器的运行环境）
   - 你已经装好了（游戏目录下有 `dinput8.dll` 和 `reframework/` 文件夹即代表已装）。
2. **修改器本体**（`reframework/autorun/re3_trainer.lua`）
   - 放进游戏目录的 `reframework\autorun\` 里即可，无需编译。
3. **中文字体支持**（想看中文界面就做这一步）
   - 确认游戏根目录（`re3.exe` 旁边）有一个 **0 字节的空文件**：
     `reframework_pictographic.mode`
   - 有它，REFramework 就会用内置中文字体渲染界面。
   - 没有它界面会变成英文（也能用，只是没有中文）。

### 2.2 启动游戏

正常从 Steam 启动游戏即可。加载后日志会显示：

```
[RE3Trainer] RE3 单机修改器 v1.4.0 加载完成 (界面=中文 · REFramework 内置中文字体, ...)
```

看到这行说明修改器已就绪。日志文件位于游戏目录的 `re2_framework_log.txt`。

### 2.3 备份存档（强烈建议）

改数据前先备份一次：

```
C:\Program Files (x86)\Steam\userdata\<你的SteamID>\952060\remote\
```

把整个 `remote` 文件夹复制一份即可。修改器虽然做了写入校验和失败回滚，
但“一击必杀”等开关本身可能影响游戏进程（比如提前杀死剧情敌人），备份最保险。

## 三、第一次使用（5 分钟上手）

### 第 1 步：打开修改器界面

游戏里按 **Insert** 键，会出现 REFramework 的菜单窗口。
在 **Script Generated UI** 分类下找到 **“RE3 单机修改器 v1.4.0”**，点开展开。

### 第 2 步：载入存档

不载入存档时，界面顶部会显示：

> 还没有进入游戏存档。请先载入一个存档，再使用修改器。

随便载入一个存档后，这里会变成“游戏状态：游戏中”。

### 第 3 步：试一个功能

勾选 **“无敌（不会掉血） [F1]”**，同时看屏幕左上角，应出现绿色字：

```
RE3 修改器 · 已开启功能
F1 无敌
```

看到这行绿字 = 热键和功能都已生效。取消勾选，绿字消失。

### 第 4 步：了解两条铁律

1. **改道具类数据（道具箱取出、刷取物品/武器）前，先按 Esc 暂停游戏。**
   没暂停就点“放入背包”会被拒绝，日志提示“请先在游戏中暂停 (Esc)”。
2. **改完后手动存档一次。** 修改器不会自动保存，不存档重进游戏就没了。

做到这里你就已经会用了。下面是各功能的详细说明。

## 四、功能详解

每个功能开关都写着“名称（效果）”，下方灰字是它的前提和风险。
按 F 键或勾选都可以开关，效果完全一样。

### 4.1 无敌（不会掉血）[F1]

- **效果**：玩家受到攻击不掉血，生命值自动维持在正常上限。
- **说明**：同时使用游戏自带的无敌字段和受击判定拦截，双保险。
- **注意**：剧情“寄生”状态下不拦截（避免剧情卡住）。
  如果你装了 Auto-Dodge.lua 这类脚本，玩家本来就不会受伤，看不出这个开关的差异。

### 4.2 一击必杀（敌人一枪就死）[F2]

- **效果**：敌人受到伤害时，伤害直接放大到 99999。
- **注意**：只作用于敌人，绝不会作用于玩家和友方。
  但可能提前杀死剧情敌人或跳过演出，**建议只在战斗时开启，过剧情时关掉**。

### 4.3 无限弹药（通常不用装填）[F3]

- **效果**：手上武器的弹匣数量保持 9999，通常感觉不到需要装填。
- **注意**：备弹（库存里的弹药）是否消耗取决于武器类型。

### 4.4 无限物品（消耗品不减少）[F4]

- **效果**：药草、手雷、弹药盒等消耗品数量保持 99。
- **注意**：钥匙和剧情道具不会被改，避免影响解谜。

### 4.5 小刀耐久（目前只检测，不修改）[F5]

- **现状**：RE3 的小刀耐久数据位置比较特殊，目前脚本会收集候选数据写进日志，
  **开启后不会改变任何游戏数据**。
- **用途**：配合 F10 导出排查文件，帮作者定位耐久字段；确认后会实现真正的不磨损。

### 4.6 完美闪避（随时可闪避）[F6]

- **效果**：让角色随时具备紧急闪避判定。
- **注意**：可能影响部分敌人行为；如果装了 Auto-Dodge.lua，此功能与它重复。

### 4.7 游戏速度（调快 / 调慢）[F7]

- **效果**：改写引擎时间缩放，0.10（很慢）~ 5.00（很快），1.00 = 正常。
- **用法**：勾选后拖动滑条，或点快捷按钮：
  - `0.25x（慢动作）`：子弹时间
  - `0.5x（慢一点）`
  - `2x（快进）`
- **注意**：只影响游戏时间，不影响菜单；打开后记得恢复 1.00 再正常游玩。

### 4.8 回满血量（一次性）[F8]

- **效果**：点一下（或按 F8）把当前生命恢复到正常上限。
- **说明**：是“当前上限”而非 9999，血条不会超限。

## 五、刷取物品与武器（重点）

这两个功能可以把你**从来没有获得过**的物品/武器直接放进背包。

### 5.1 操作步骤（两者相同）

1. **载入存档，进入游戏**。
2. **按 Esc 暂停游戏**（必须，否则按钮会被拒绝）。
3. 按 Insert 打开修改器，找到：
   - **“刷取物品（直接放入背包，未获得的也能刷）”**
   - **“刷取武器（每次一把，直接放入背包）”**
4. 第一次使用点 **“加载可刷取物品列表（首次使用点这里）”**。
   脚本会扫描游戏物品表，列出所有有效物品（约 300+ 项）。
5. 在搜索框输入名称或编号（比如“药草”“弹药”“31”），列表会实时过滤。
6. 用“刷取数量（1~999）”滑条选择数量（武器没有数量，每次一把）。
7. 点物品右侧的 **“放入背包”**。
8. 成功后日志显示（按 F10 也可确认）：
   ```
   [RE3Trainer] 已刷取: 绿色药草 x5 -> 背包槽 3
   [RE3Trainer] 已刷取武器: Samurai Edge (WT 12) -> 背包槽 5
   ```
9. **关闭修改器菜单，在游戏里手动存档。**

### 5.2 物品和武器的区别

| | 物品 | 武器 |
|---|---|---|
| 列表来源 | 物品 ID 表（药草、弹药、钥匙等） | 武器类型表（各枪械、小刀等） |
| 数量 | 1~999 | 固定 1 把 |
| 配件 | — | 无配件 |
| 弹药 | — | 1 发（进游戏后自己补充） |
| 查重 | 不查重 | **刷前检查背包、装备、游戏道具箱，已有则拒绝** |

### 5.3 武器刷取的查重规则

点“放入背包”刷武器前，脚本会检查三个地方：

1. 背包里是否已有同型号武器；
2. 装备位（手上/枪套）是否已有；
3. 游戏道具箱里是否存着同型号。

任何一处已有，就会拒绝刷取并写日志说明原因，防止重复刷出多把。
武器已在道具箱里时，请直接在游戏里用道具箱取出。

### 5.4 风险提示

- **钥匙、剧情道具**：刷出来可能导致某些剧情/解谜跳过或卡住，建议先备份存档。
- **武器**：只建议刷玩家武器列表里的武器；列表已过滤掉大部分敌人/内部武器，
  但仍可能有个别型号在游戏里表现异常，刷出后立刻存档前先试装备一下。
- 刷出来的武器是**无配件、1 发**的状态，配件和弹药需要在游戏里正常获取/购买。

## 六、游戏道具箱（取出已有物品）

这个功能是把**游戏道具箱里已经存着的东西**取到背包，等于一个随身道具箱。

### 6.1 操作步骤

1. 载入存档，按 Esc 暂停。
2. 打开修改器，找到 **“游戏道具箱（可取出到背包）”**。
3. 点 **“读取 / 刷新道具箱”**。首次读取后会列出箱内物品：
   ```
   道具箱 1：手枪弹药 x60   [放入背包]
   道具箱 1：急救喷雾 x1    [放入背包]
   道具箱 2：冲锋枪弹药 x200 [放入背包]
   ```
   游戏里有**两组**道具箱数据，分别显示为 1 / 2。
4. 点想取的物品旁的 **“放入背包”**。
5. 成功后该物品从道具箱消失、出现在背包；日志：
   ```
   [RE3Trainer] 已取出: 手枪弹药 x60 -> 背包槽 2
   ```

### 6.2 安全机制

- 写入背包后**读回校验**，确认数量正确才清空道具箱条目；
- 任一步失败会**自动回滚**，不会出现“背包有、箱子也有”的复制情况；
- 武器条目只显示不提供按钮，请用游戏自己的道具箱取出。

### 6.3 提醒

- 每次取完后重新点一次“读取 / 刷新道具箱”，列表才会更新。
- 取完记得手动存档。

## 八、界面语言切换

1. 打开修改器界面，找到 **“显示与语言”** 区块。
2. **“界面语言（默认中文）”** 下勾选 `中文界面` 或 `English UI`。
3. 立即生效并自动保存，下次启动保持所选语言。

- 中文界面依赖游戏根目录的 `reframework_pictographic.mode` 文件。
  若该文件缺失，语言选项会只剩 English，并提示中文字体不可用。
- 切换语言不影响任何开关状态。

## 九、常见问题（FAQ）

### Q1：按 Insert 没反应 / 找不到修改器界面？

- 确认游戏目录下有 `reframework/autorun/re3_trainer.lua`；
- 看日志 `re2_framework_log.txt` 有没有 `[RE3Trainer] ... 加载完成`；
- Insert 键可能被其他软件（输入法、录屏软件）占用，换一个时机按或关掉占用程序。

### Q2：界面是英文，怎么变中文？

确认游戏根目录（re3.exe 旁边）有 0 字节文件 `reframework_pictographic.mode`，重启游戏。
文件必须在游戏根目录，放进 reframework 子文件夹无效。

### Q3：按 F1 没有绿字，热键不生效？

- 打开修改器菜单，展开 **“高级 / 排错”**，看 **“热键识别方式”**：
  - “正常”：热键应该可用；
  - “兼容模式（按住移动键时可能不响应，松开再按）”：先松开 WASD/方向键再按 F 键；
  - “不可用（请用菜单操作）”：直接用界面勾选，功能完全一样。
- 无论哪种情况，**用界面勾选永远可用**。

### Q4：点了“放入背包”没反应？

看这几个条件是否满足：

1. **游戏暂停了吗？**（必须 Esc 暂停）
2. **载入存档了吗？**（主菜单里无效）
3. **背包满了吗？**（会提示“背包没有可用空格子”）
4. 武器刷取时三个位置已有同型号武器也会拒绝。

所有拒绝原因都会写在日志里（按 F10 导出，或直接看 `re2_framework_log.txt`）。

### Q5：刷出来的武器没有弹药/无法装备？

武器是按“无配件、1 发”创建的。先试装备和开一枪；如果异常，
把日志中 `[RE3Trainer] 已刷取武器` 那一行发给作者，注明是哪把武器。

### Q6：某项功能显示不生效 / 数据没变？

- 展开高级/排错区，看 **“弹药识别结果 / 小刀识别结果 / 功能挂接状态”**；
- 点 **“重新识别游戏数据”** 后重试；
- 仍无效就点 **“导出排查文件”**，把生成的
  `reframework/data/re3_trainer_dump.txt` 发给作者。

### Q7：独立窗口能显示但点不了？

这是 REFramework 的机制：只有 Insert 菜单打开时才接收输入。
**按 Insert 打开菜单后**独立窗口即可正常点击。窗口默认在 REFramework 菜单右侧。

### Q8：游戏更新后修改器失效？

RE 引擎更新可能改变内部字段。让修改器重新识别：高级/排错 → “重新识别游戏数据”；
还不行就 F10 导出排查文件发给作者。

### Q9：和 Raz0r Ultimate Trainer / Auto-Dodge 冲突吗？

- Auto-Dodge.lua 会让玩家不掉血，导致“无敌”开关看不出差别；两者功能重叠但可共存。
- Raz0r 的 C++ 修改器与本修改器功能高度重叠，**建议只用一套**，避免互相覆盖数值。

### Q10：会封号吗？

修改器只读写本机游戏内存中的单机数据，不修改联机数据、不上传任何内容。
但请**只在天梯/排行榜无关的单机流程里使用**；游戏自身的统计（击杀数、步数等）
会被改动，这是所有修改器的固有影响。

## 十、安全须知与卸载

### 安全须知

1. **仅供单机离线娱乐**，勿用于联机、排行榜、速通认证等场景。
2. **改数据前备份存档**：`...\Steam\userdata\<SteamID>\952060\remote\`。
3. 刷取钥匙/剧情道具、开启一击必杀可能影响剧情流程——不确定就先存档。
4. 脚本所有游戏访问都有错误保护，单项失败会写日志而不是让游戏崩溃；
   但“一击必杀”等仍可能触发游戏自身逻辑异常，出问题先关开关。

### 卸载

1. 删除 `reframework\autorun\re3_trainer.lua`；
2. （可选）删除以下自动生成的文件：
   - `reframework\data\re3_trainer.json`（开关状态）
   - `reframework\data\re3_trainer_dump.txt`（排查文件）
   - `reframework\data\re3_trainer_itemprobe.txt`（探针文件）
3. 重启游戏即恢复原状。REFramework 本体如不再需要，另行卸载。
